## J3 贪心

### 常考类型

1.  **区间问题**：区间选点、区间覆盖、最多不相交区间
2.  **调度问题**：活动安排、任务截止时间、加工顺序
3.  **分配问题**：饼干分配、会议室分配、田忌赛马
4.  **背包变体**：分数背包（可分割，按性价比贪心）
5.  **构造/交换论证**：通过排序后依次处理，证明局部最优推出全局最优

### 核心技能

-   **排序 + 贪心策略**：先按某个关键字排序，再线性扫描
```cpp
sort(a, a + n, cmp);          // 按结束时间/性价比/截止时间排序
for (int i = 0; i < n; i++)
{
    // 依次决策
}
```
-   **区间选点 / 最多不相交区间**（按右端点排序）：
```cpp
sort(a, a + n, [](Node x, Node y){ return x.r < y.r; });
int cnt = 0, last = -INF;
for (int i = 0; i < n; i++)
{
    if (a[i].l > last)
    {
        cnt++;
        last = a[i].r;
    }
}
```
-   **区间覆盖**（按左端点排序，维护当前最远右端）：
```cpp
sort(a, a + n, [](Node x, Node y){ return x.l < y.l; });
int cur = 0, far = 0, i = 0, ans = 0;
while (cur < target)
{
    while (i < n && a[i].l <= cur)
    {
        far = max(far, a[i].r);
        i++;
    }
    if (far == cur)   // 无法覆盖
    {
        break;
    }
    cur = far;
    ans++;
}
```
-   **分数背包**（按单位价值降序）：
```cpp
// 避免浮点，交叉相乘比较
sort(a, a + n, [](Item x, Item y){ return x.v * y.w > y.v * x.w; });
```
-   **优先队列维护当前最优**：
```cpp
priority_queue<int, vector<int>, greater<int>> pq;
```

### 易错点

-   **贪心策略选错**：区间问题中"按左端点""按右端点""按长度"排序结果不同，要针对题型选对
-   **忘记排序**或排序关键字写反（升/降序搞混）
-   **边界条件**：区间端点是否包含（`>` 还是 `>=`）、`target` 恰好被覆盖的情况
-   **性价比比较用浮点**会产生精度误差，尽量交叉相乘比较
-   **贪心不适用所有题**：0/1 背包不能贪心，要能判断题目是否满足贪心选择性质
-   多组数据时**变量、队列要重新初始化**
-   **无法完成时**的判定（如覆盖不到目标、活动冲突无法安排）要单独处理，避免死循环
