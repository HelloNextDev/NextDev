## J3 贪心（CSP-J 范围）

### 常考类型

1. **排序贪心**：先排序再按顺序取，如拼数、删数、排队打水
2. **区间贪心**：区间选点、最大不相交区间、区间覆盖（CSP-J 复赛必考王牌）
3. **决策型贪心**：边走边决策，如公路加油（2023 T2）
4. **简单选择贪心**：无需复杂排序，直接按规则择优

### 核心技能

**排序贪心**（拼数型：数字降序拼接即最大）：
```cpp
// 2025 T1 拼数：统计数字出现次数，从 9 到 0 依次输出
int cnt[10] = {0};
for (char c : s)
{
    if (isdigit(c)) cnt[c - '0']++;
}
for (int d = 9; d >= 0; d--)
{
    while (cnt[d]--) cout << d;
}
```

**区间贪心**（最大不相交区间，按右端点升序）：
```cpp
sort(a, a + n, [](Node x, Node y)
{
    return x.r < y.r;
});
int cnt = 0, last = -INF;
for (int i = 0; i < n; i++)
{
    if (a[i].l >= last)   // 端点是否包含看题意，有时用 >
    {
        cnt++;
        last = a[i].r;
    }
}
```

**决策型贪心**（公路加油：在能到达的范围内，找第一个油价更低的站）：
```cpp
// 核心规则：只在当前站买够开到“下一个更便宜站”的油
// 若后面没有更便宜的，就买够到终点的油
```

### 易错点

- **区间排序规则选错**：最大不相交区间按**右端点**排序，不是左端点
- **边界判断**：区间端点是否包含（`>=` 还是 `>`），`last` 初始值设置
- **多关键字排序写错**：结构体 `cmp` 中并列情况处理不当
- **贪心不成立**：0/1 背包、部分 DP 题不能用贪心，需判断是否满足最优子结构和无后效性
- **决策型贪心的“向后看”**：公路题中要找到下一个更便宜的站再决定买多少，不能只看当前站
- 多组数据时变量、数组要重新初始化
