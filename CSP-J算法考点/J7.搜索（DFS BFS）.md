## 搜索（DFS BFS）

### 常考类型

1.  **DFS 全排列 / 组合枚举**：回溯框架的标准练手，初赛完善程序常考
2.  **DFS 连通块**：网格中数岛屿/水坑/细胞，标记访问后向四周扩展
3.  **DFS 剪枝**：N 皇后、小木棍（2024 T3 部分分）
4.  **BFS 无权图最短路**：迷宫最少步数，第一次到达终点即为最短
5.  **BFS 状态搜索**：加工零件（奇偶分层距离）
6.  **DFS/BFS 混用**：BFS 求最短距离，DFS 求所有方案或连通性

### 核心技能

**DFS全排列**（回溯）：

```cpp
int path[N];
bool st[N];
void dfs(int u)
{
	if (u == n)
	{
		for (int i = 0; i < n; i++) cout << path[i] << ' ';
		cout << "\n";
		return;
	}
	for (int i = 1; i <= n; i++)
	{
		if (!st[i])
		{
			path[u] = i;
			st[i] = true;
			dfs(u + 1);
			st[i] = false;
		}
	}
}
```

**DFS 网格连通块（迷宫/水坑类）**：
```cpp
int dx[4] = {-1, 0, 1, 0};
int dy[4] = {0, 1, 0, -1};
void dfs(int x, int y)
{
	vis[x][y] = true;
	for (int i = 0; i < 4; i++)
	{
		int nx = x + dx[i], ny = y + dy[i];
		if (nx >= 0 && nx < n && ny >= 0 && ny < m && !vis[nx][ny] && g[nx][ny] == '.')
			dfs(nx, ny);
	}
}
// 主函数中双重循环，每遇到一个未访问的合法格子，ans++ 后 dfs(i,j)
```
八方向连通块把 `dx/dy` 扩为 8 个方向即可。

**BFS 迷宫最短路**：

int n, m;
int g[N][N];
int d[N][N]
pair<int, int> q[N * N];
int bfs()
{
	int hh = 0, tt = 0;
	q[0] = {0, 0};
	memset(d, -1, sizeof d);
	int dx[4] = {-1, 0, 1, 0}, dy[4] = {0, 1, 0, -1};
	d[0][0] = 0;
	while (hh <= tt)
	{
		auto t = q[hh++];
		for (int i = 0; i < 4; i++)
		{
			int x = t.first + dx[i], y = t.second + dy[i];
			if (x >= 0 && x < n && y >= 0 && y < m && g[x][y] == 0 && d[x][y] == -1)
			{
				d[x][y] = d[t.first][t.second] + 1;
				q[++tt] = {x, y};
			}
		}
	}
	return d[n - 1][m - 1];
}
