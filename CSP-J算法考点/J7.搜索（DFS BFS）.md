## 搜索（DFS BFS）

### 常考类型

1.  **DFS 全排列 / 组合枚举**：回溯框架的标准练手，初赛完善程序常考
2.  **DFS 连通块**：网格中数岛屿/水坑/细胞，标记访问后向四周扩展
3.  **DFS 剪枝**：N 皇后、小木棍（2024 T3 部分分）
4.  **BFS 无权图最短路**：迷宫最少步数，第一次到达终点即为最短
5.  **BFS 状态搜索**：加工零件（奇偶分层距离）
6.  **DFS/BFS 混用**：BFS 求最短距离，DFS 求所有方案或连通性

### 核心技能

**DFS全排列**（回溯）：

```cpp
int path[N];
bool st[N];
void dfs(int u)
{
	if (u == n)
	{
		for (int i = 0; i < n; i++) cout << path[i] << ' ';
		cout << "\n";
		return;
	}
	for (int i = 1; i <= n; i++)
	{
		if (!st[i])
		{
			path[u] = i;
			st[i] = true;
			dfs(u + 1);
			st[i] = false;
		}
	}
}
```

**DFS 网格连通块（迷宫/水坑类）**：
```cpp
int dx[4] = {-1, 0, 1, 0};
int dy[4] = {0, 1, 0, -1};
void dfs(int x, int y)
{
	vis[x][y] = true;
	for (int i = 0; i < 4; i++)
	{
		int nx = x + dx[i], ny = y + dy[i];
		if (nx >= 0 && nx < n && ny >= 0 && ny < m && !vis[nx][ny] && g[nx][ny] == '.')
			dfs(nx, ny);
	}
}
// 主函数中双重循环，每遇到一个未访问的合法格子，ans++ 后 dfs(i,j)
```
八方向连通块把 `dx/dy` 扩为 8 个方向即可。

**BFS 迷宫最短路**：

```cpp
int n, m;
int g[N][N];
int d[N][N]
pair<int, int> q[N * N];
int bfs()
{
	int hh = 0, tt = 0;
	q[0] = {0, 0};
	memset(d, -1, sizeof d);
	int dx[4] = {-1, 0, 1, 0}, dy[4] = {0, 1, 0, -1};
	d[0][0] = 0;
	while (hh <= tt)
	{
		auto t = q[hh++];
		for (int i = 0; i < 4; i++)
		{
			int x = t.first + dx[i], y = t.second + dy[i];
			if (x >= 0 && x < n && y >= 0 && y < m && g[x][y] == 0 && d[x][y] == -1)
			{
				d[x][y] = d[t.first][t.second] + 1;
				q[++tt] = {x, y};
			}
		}
	}
	return d[n - 1][m - 1];
}
```
**核心原则：入队时立刻标记 `d = 距离`，不要等出队才标记**，否则同一状态重复入队导致 MLE/TLE。

**BFS 奇偶分层（加工零件类，进阶）**：

```cpp
int dis[N][2];   // dis[v][0]=偶数最短路, dis[v][1]=奇数最短路
// BFS 转移时奇偶性翻转：dis[v][1] 由 dis[u][0]+1 更新，反之亦然
```

询问 `(a, L)` 时，若 `dis[a][L % 2] <= L` 则输出 Yes。

### 易错点

-   **DFS 忘记回溯**：`st[i] = false` 漏写，后续分支状态错误，全排列少输出大量结果
-   **DFS 递归边界写错**：`u == n` 还是 `u > n`，差一导致多搜一层或少输出最后一层
-   **BFS 入队顺序错误**：先标记再入队，不要先入队再标记；判断条件中 `d[nx][ny] == -1` 和边界检查顺序可互换，但**标记必须发生在入队那一刻**
-   **队列数组开小**：BFS 队列容量取 `N * N` 或 `N * M`，不要只开 `N`
-   **DFS 爆栈**：递归深度超过 1e5 量级时考虑改 BFS 或手动栈；CSP-J 网格题通常深度有限，但全排列 n 较大时注意
-   **剪枝缺失导致 TLE**：枚举类 DFS 在内层找到解后及时返回，或提前判断剩余元素是否足够；N 皇后用 `col/dg/udg` 三个标记数组剪枝
-   **多组数据未清空**：`vis`、`d`、`st` 在每组数据前重置
-   **DFS 与 BFS 选择错误**：求**最少步数/最短距离**用 BFS；求**所有方案/连通块/存在性**用 DFS。求最短路用 DFS 虽然能出解但不是最优，可能 TLE
