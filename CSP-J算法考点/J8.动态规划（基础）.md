## J8 动态规划（基础）

### 常考类型

**1. 0/1 背包**

状态 `f[i][j]`：只考虑前 `i` 件，容量 `j` 时的最大价值。转移：不选 `f[i-1][j]`；选（`j >= w[i]`）`f[i-1][j-w[i]] + v[i]`。

一维优化核心：
```cpp
for (int i = 1; i <= n; i++)
    for (int j = W; j >= w[i]; j--)   // 必须逆序
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```
**逆序**：保证每件物品只用一次。写成正序就变成完全背包，答案全错。

**2. 完全背包**

与 0/1 背包唯一区别：一维优化时**正序**枚举容量：
```cpp
for (int i = 1; i <= n; i++)
    for (int j = w[i]; j <= W; j++)   // 正序
        f[j] = max(f[j], f[j - w[i]] + v[i]);
```
正序时 `f[j-w[i]]` 可能已经包含了第 `i` 件物品，恰好实现“无限次选取”。2019 T3 纪念品就是完全背包的变形：每天以“今天价格”为重量、“明天价格-今天价格”为价值跑一遍完全背包。

**3. 线性 DP**

**最长上升子序列（LIS）**：`f[i]` 表示以 `a[i]` **结尾**的最长上升子序列长度，不是“前 i 个”的答案。转移 `if (a[j] < a[i]) f[i] = max(f[i], f[j] + 1)`，最终答案为 `max(f[i])` 而非 `f[n]`。

**最大子段和**：`f[i] = max(a[i], f[i-1] + a[i])`，仅与前一项有关。

**网格路径 DP**：`f[i][j]` 从上方或左方转移，如摘花生、最低通行费。2020 T4 方格取数是变体，需要三维状态处理方向限制。

**4. 区间 DP（了解）**

NOI 大纲入门级包含“简单区间类型动态规划”，难度 5。典型题石子合并：`f[l][r]` 表示合并区间 `[l, r]` 的最小代价，枚举分割点 `k`，`f[l][r] = min(f[l][k] + f[k+1][r] + sum(l, r))`。CSP-J 复赛直接考区间 DP 的概率低于背包和线性 DP。

### 核心技能

**DP 解题四步**（写代码前必须走完）：
1. **状态定义**：`f[i]` 或 `f[i][j]` 到底表示什么，以“结尾”还是“前 i 个”
2. **转移方程**：当前状态由哪些更小状态推出
3. **初始化**：`f[0]` 或 `f[0][0]` 是什么，求最值还是方案数
4. **遍历顺序**：保证用到的子状态已经算好

**一维背包的遍历方向速查**：
| 背包类型 | 容量 `j` 遍历方向 | 原因 |
|---|---|---|
| 0/1 背包 | **逆序** `W → w[i]` | 防止同一物品重复选 |
| 完全背包 | **正序** `w[i] → W` | 允许同一物品重复选 |

**方案数 DP 与最值 DP 的区别**：
- 求最值：`f[j] = max(...)`
- 求方案数：`f[j] = f[j] + f[j - w[i]]`，且 `f[0] = 1`（容量 0 有一种空方案）

### 易错点

- **0/1 背包写成正序**：这是最高频的考试陷阱，方向记反全错
- **LIS 状态含义混淆**：`f[i]` 是以 `a[i]` **结尾**，不是“前 i 个的最大值”，最终答案要取 `max(f[1..n])`
- **初始化错误**：不要求装满时 `f` 全 0；要求“恰好装满”时 `f[0]=0`、其余 `-∞`，最后判断 `f[W]` 是否可达
- **转移时漏掉容量判断**：选第 `i` 件的前提是 `j >= w[i]`
- **二维数组开不下**：`n, W` 达到 1e4 时二维 `f[n][W]` 会 MLE，必须压成一维
- **方案数 DP 边界漏 `f[0]=1`**：导致所有方案数全为 0
- **多组数据未清空 `f` 数组**
- **区间 DP 枚举顺序写反**：必须按区间长度从小到大枚举，保证小区间先算好
