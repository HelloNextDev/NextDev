## J2 排序

### 常考类型

1.  **基础排序算法实现**：冒泡、选择、插入排序的手写
2.  **结构体排序**：多关键字排序（成绩、姓名、年龄等）
3.  **sort + 自定义比较函数**：`cmp` 函数写法，升降序切换
4.  **去重与统计**：排序后去重、找众数、找中位数
5.  **第 k 小/第 k 大**：排序后取下标，或部分排序思想

### 核心技能

-   **自定义比较函数**：
```cpp
bool cmp(int a, int b) {
    return a > b;  // 降序；a < b 为升序
}
sort(a, a + n, cmp);
```
-   **结构体多关键字比较**：
```cpp
struct Node
{
	int sc, id;
};
bool cmp(Node a, Node b) {
    if (a.sc != b.sc) return a.sc > b.sc;  // 第一关键字降序
    return a.id < b.id;                                 // 第二关键字升序
}
-   **快速排序模板**：
    

cpp

void quickSort(int l, int r) {
    if (l >= r) return;
    int i = l, j = r, pivot = a[(l + r) / 2];
    while (i <= j) {
        while (a[i] < pivot) i++;
        while (a[j] > pivot) j--;
        if (i <= j) { swap(a[i], a[j]); i++; j--; }
    }
    quickSort(l, j);
    quickSort(i, r);
}

-   **归并排序模板**：
    

cpp

void mergeSort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(l, mid);
    mergeSort(mid + 1, r);
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else              tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r)   tmp[k++] = a[j++];
    for (int p = l; p <= r; p++) a[p] = tmp[p];
}

-   **交换与比较**：`swap(a, b)`、`sort(begin, end)`
		
### 易错点

-   比较函数必须满足**严格弱序**（不能写 `>=`，否则可能 RE）
-   `sort` 区间是**左闭右开**：`sort(a, a + n)` 而非 `a + n - 1`
-   结构体排序时**并列情况**要按题目要求处理第二关键字
-   下标从 0 还是 1 开始，取第 k 小时注意 `a[k-1]` 还是 `a[k]`
-   多组数据时**数组要清空/重新初始化**
-   排序后**原始下标丢失**问题，需要时用结构体存 id
