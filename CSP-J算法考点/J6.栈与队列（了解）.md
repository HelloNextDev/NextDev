## J6 栈与队列（了解）

### 常考类型

1. **BFS 的底层工具**（队列）：复赛 T3/T4 搜索题必用，队列写错直接全盘崩
2. **括号匹配 / 表达式求值**（栈）：偶见 T2 级别字符串+栈结合
3. **单调栈**：求左右第一个更大/更小元素，可能作为某题的子步骤
4. **单调队列**：滑动窗口最值，复赛直接考概率低，了解即可

### 核心技能（数组模拟）

**数组模拟队列**（BFS）：
```cpp
int q[N], hh = 0, tt = -1;   // hh 队头，tt 队尾
q[++tt] = x;                 // 入队
hh++;                        // 出队
if (hh <= tt) { /* 非空 */ } // 判断空
q[hh];                       // 取队头
```
BFS 框架中，队列存的是**状态（坐标/节点编号）**，入队时标记已访问，出队时扩展邻居。

**数组模拟栈**：
```cpp
int stk[N], tt = 0;   // tt 为栈顶指针，0 表示空
stk[++tt] = x;        // 入栈
tt--;                 // 出栈
if (tt > 0) { /* 非空 */ }
stk[tt];              // 取栈顶
```

**单调栈**（求每个数左边第一个比它小的数）：
```cpp
int stk[N], tt = 0;
for (int i = 0; i < n; i++)
{
    while (tt > 0 && stk[tt] >= a[i]) tt--;  // 维护单调递增
    if (tt > 0) cout << stk[tt] << " ";
    else        cout << "-1 ";
    stk[++tt] = a[i];
}
```

**单调队列**（滑动窗口最小值，窗口大小 k）：
```cpp
int q[N], hh = 0, tt = -1;
for (int i = 0; i < n; i++)
{
    if (hh <= tt && q[hh] < i - k + 1) hh++;      // 队头滑出
    while (hh <= tt && a[q[tt]] >= a[i]) tt--;    // 维护单调递增
    q[++tt] = i;                                   // 存下标
    if (i >= k - 1) cout << a[q[hh]] << " ";
}
```

**括号匹配**（栈的典型复赛应用）：
```cpp
bool check(string s)
{
    int stk[N], tt = 0;
    for (char c : s)
    {
        if (c == '(' || c == '[' || c == '{') stk[++tt] = c;
        else
        {
            if (tt == 0) return false;
            char t = stk[tt--];
            if (c == ')' && t != '(') return false;
            if (c == ']' && t != '[') return false;
            if (c == '}' && t != '{') return false;
        }
    }
    return tt == 0;
}
```

### 易错点（复赛实战角度）

- **栈与队列 `tt` 初始值混淆**：栈 `tt = 0`，队列 `tt = -1`，写混直接越界或空判断错
- **队列空判断**：`hh <= tt` 才是非空，`hh < tt` 是错的
- **BFS 中队列存什么要想清楚**：存坐标就开两个数组或存 pair，存节点编号就开一维数组，不要混
- **入队即标记访问**：BFS 若出队才标记，同一状态可能重复入队导致 MLE/TLE
- **单调队列存下标不存值**：判断滑出窗口必须用下标
- **单调队列操作顺序**：先判队头滑出 → 再维护单调性 → 最后入队，顺序不能乱
- **单调栈弹栈条件**：`>=` 还是 `>` 取决于是否保留相等元素，求“第一个更小”用 `>=`
- **复赛定位**：不要把单调栈/单调队列当重点刷，它们是子步骤工具；真正要练到条件反射的是**用队列写 BFS**
