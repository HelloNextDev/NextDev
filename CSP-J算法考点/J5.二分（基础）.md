## J5 二分（基础）

### 常考类型

1. **二分答案（复赛核心）**：答案具有单调性时，把“求最优解”转化为“判定可行性”。典型关键词：**最大值最小**、**最小值最大**。2025 J T3 异或和涉及二分+前缀和。
2. **实数二分**：求方程根、切绳子等，控制精度 `eps`。
3. **二分与前缀和结合**：先预处理前缀和，再二分查找目标区间。

### 核心技能

**整数二分查找（找第一个 ≥ x 的位置）**：
```cpp
int l = 0, r = n;  // 左闭右开，答案范围 [0, n]
while (l < r)
{
    int mid = l + (r - l) / 2;
    if (a[mid] >= x) r = mid;   // mid 可能是答案，保留
    else             l = mid + 1; // mid 不满足，舍去
}
return l;  // 若 l == n 表示无解
```

**二分答案通用框架（求最大值最小 / 最小值最大）**：
```cpp
int l = 下界, r = 上界, ans = -1;
while (l <= r)
{
    int mid = l + (r - l) / 2;
    if (check(mid))   // mid 可行
    {
        ans = mid;
        // 根据题目方向决定：求最小就 r = mid - 1；求最大就 l = mid + 1
    }
    else
    {
        // 与上面相反
    }
}
```
`check(mid)` 的**单调性**是二分答案成立的前提，写代码前先确认：mid 可行时，更大（或更小）的值是否一定可行。

**`mid` 防溢出**：一律写 `mid = l + (r - l) / 2`，不要写 `(l + r) / 2`。

### 易错点

- **区间约定混用**：左闭右闭 `l <= r` 配 `mid ± 1`，左闭右开 `l < r` 配 `r = mid / l = mid + 1`。两套写法不能混搭，否则死循环或漏解。
- **二分查找前提**：数组**必须有序**。题目给无序数组问能否二分，答案是不能。
- **`check` 函数单调性不成立**：二分答案直接失效。写之前先验证“mid 可行 ⇒ 更大/更小的值也可行”是否成立。
- **边界值验证**：填完代码或写完模板，用 `n=1`、`n=2`、目标在首/尾的样例手动跑一遍。2024 初赛完善程序的坑就是 `r = mid` 还是 `r = mid - 1`。
- **实数二分的精度**：循环条件用 `r - l > eps`，`eps` 一般取 `1e-6` 或 `1e-7`，题目有精度要求时按题目调整。
- **初赛概念题**：1000 个元素二分查找最多比较 **10 次**（因为 2⁹=512 < 1000 ≤ 1024=2¹⁰）。
