## J4 前缀和与差分

### 常考类型

1. **一维前缀和**：多次查询区间和，`O(n)` 预处理 + `O(1)` 查询
2. **一维差分**：多次区间修改，将区间操作转为两个端点操作
3. **二维前缀和**：子矩阵求和，容斥原理维护
4. **异或前缀和**：区间异或查询的变体，利用 `x^x=0` 性质
5. **差分还原**：对差分数组求前缀和得到修改后的原数组

### 核心技能

**一维前缀和**（下标从 1 开始，`s[0]=0`）：
```cpp
// 预处理 O(n)
s[i] = s[i - 1] + a[i];

// 查询区间 [l, r] 的和 O(1)
sum = s[r] - s[l - 1];
```
这是 CSP-J 最基础、最高频的模板，必须做到条件反射。

**一维差分**（区间 `[l, r]` 全部加 `k`）：
```cpp
// 构建差分（或直接在原数组上操作）
d[i] = a[i] - a[i - 1];

// 区间修改：只改两个位置
d[l] += k;
d[r + 1] -= k;

// 还原：对 d 求前缀和得到修改后的 a
for (int i = 1; i <= n; i++)
{
    d[i] += d[i - 1];
    a[i] = d[i];   // 或直接使用 d[i]
}
```
差分把 `O(len)` 的区间修改降为 `O(1)`，最终一次性还原。

**二维前缀和**（容斥维护）：
```cpp
// 构建
s[i][j] = a[i][j] + s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1];

// 查询左上 (x1,y1) 到右下 (x2,y2) 的子矩阵和
sum = s[x2][y2] - s[x1 - 1][y2] - s[x2][y1 - 1] + s[x1 - 1][y1 - 1];
```
二维差分同理，四个角做标记，CSP-J 阶段了解即可，优先掌握一维。

**异或前缀和**（区间异或）：
```cpp
s[i] = s[i - 1] ^ a[i];
// 查询 [l, r] 异或值
ans = s[r] ^ s[l - 1];
```
异或没有减法，用 `^` 代替 `-`，性质是 `x ^ x = 0`。

### 易错点

- **下标从 0 还是 1 开始**：前缀和强烈建议从 1 开始，`s[0]=0` 可避免 `l=0` 时 `s[l-1]` 越界
- **差分还原忘记求前缀和**：`d[l]+=k; d[r+1]-=k;` 只是标记，必须再扫一遍累加才能得到最终数组
- **`r+1` 越界**：差分修改时 `d[r+1]` 可能超出数组范围，数组要开到 `n+2`
- **数据类型溢出**：区间和可能超过 `int`，前缀和数组用 `long long`
- **二维容斥符号写反**：查询时四个项的加减顺序容易错，记不住就画图推导
- **误以为所有题都能用**：前缀和适合**静态数组多次查询**，如果数组频繁修改又频繁查询，单纯前缀和不够（需结合差分或其他结构）
- **异或前缀和套用减法**：异或是 `s[r] ^ s[l-1]`，不是 `s[r] - s[l-1]`
