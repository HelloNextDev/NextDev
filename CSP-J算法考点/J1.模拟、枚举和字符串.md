## J1 模拟、枚举与字符串

### 常考类型

1. **流程模拟**：按题目描述还原步骤，如 2024 T1 扑克牌统计、2017 T1 成绩统计
2. **二维网格模拟**：方向移动、边界判断，如 2024 T2 地图探险、2015 T2 扫雷游戏
3. **枚举与条件筛选**：有限范围内暴力枚举，如 2018 T2 龙虎斗、2016 T2 回文日期
4. **字符串基础处理**：字符统计、子串提取、格式解析，如 2019 T1 数字游戏、2018 T1 标题统计
5. **简单数学模拟**：取余、整除、进制相关，如 2021 T1 分糖果、2020 T1 优秀的拆分

### 核心技能

**方向数组 + 边界判断**（网格模拟必背）：
```cpp
int dx[4] = {0, 0, 1, -1};
int dy[4] = {1, -1, 0, 0};
// 或按题目要求：上下左右/四方向/八方向

if (nx >= 0 && nx < n && ny >= 0 && ny < m)
{
    // 合法，继续模拟
}
```

**枚举循环的变量语义要清晰**（避免逻辑嵌套混乱）：
```cpp
for (int i = 0; i < n; i++)
{
    for (int j = i + 1; j < n; j++)  // j 从 i+1 开始，避免重复对
    {
        if (a[i] + a[j] == k)
        {
            // 处理
        }
    }
}
```

**字符串读入：区分 `cin >>` 与 `getline`**：
```cpp
string s;
cin >> s;           // 遇空格停止，适合单个“单词”
getline(cin, s);    // 读整行含空格，需注意前面是否有残留换行
```

**字符串常用操作**（CSP-J 范围内）：
```cpp
s.size();                    // 长度
s += ch;                     // 拼接字符
s.substr(pos, len);          // 截取子串
s.find("xx") != string::npos // 查找，不要写 == -1
isdigit(ch); isalpha(ch);    // 字符类型判断
```

**枚举剪枝**：当 n 较大时，在内层循环找到答案后及时 `break`，避免 TLE。

### 易错点

- **边界判断写错**：网格题中 `x>=0 && x<n` 而非 `x>0`，方向数组与坐标增减对应关系要核对
- **`cin >>` 读字符串遇空格截断**：题目要求读整行时必须用 `getline`，并处理残留换行符
- **枚举范围过大导致超时**：先看数据范围，n ≤ 1000 可直接暴力，n 较大时考虑剪枝或换思路
- **字符串 `find` 判断写 `== -1`**：标准写法是 `!= string::npos`
- **模拟题步骤遗漏**：读题后用草稿纸拆分步骤，编码前写伪代码，避免逻辑跳跃
- **多组数据未清空**：字符串、数组、计数器在每组数据前要重置
- **下标从 0 还是 1 开始**：题目描述若按 1 开始，编码时注意转换，避免越界或漏算
