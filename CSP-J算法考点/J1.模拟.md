## J1 模拟

### 常考类型

1.  **日期计算**：闰年判断、某年某月某日是星期几
2.  **进制转换**：十进制转二进制/十六进制，或反向
3.  **图形输出**：打印三角形、菱形、方阵
4.  **方向移动**：机器人走格子，上下左右
5.  **简单游戏规则**：报数、约瑟夫环（模拟版）


### 2. 进制转换

**十进制 → 其他进制（短除法，倒序取余）：**

```cpp
// 十进制 n 转 b 进制（b 为 2~16）
string toBase(int n, int b) {
    if (n == 0) return "0";
    string s = "";
    while (n > 0) {
        int r = n % b;
        s += (r < 10) ? char('0' + r) : char('A' + r - 10);
        n /= b;
    }
    reverse(s.begin(), s.end());
    return s;
}
```

**其他进制 → 十进制（按位权展开）：**

```
cpp

int toDec(string s, int b) {
    int n = 0;
    for (char c : s) {
        int d = (c >= '0' && c <= '9') ? c - '0' : c - 'A' + 10;
        n = n * b + d;
    }
    return n;
}
```

**常见考法：**

-   十进制 ↔ 二进制 / 八进制 / 十六进制
-   任意进制互转（先转十进制再转目标进制，或用短除法直接除）
-   二进制转十六进制（4位一组）、二进制转八进制（3位一组）
-   判断回文数（转成某进制后判断）

**易错：**

-   `n == 0` 要特判输出 `"0"`
-   十六进制字母大小写
-   大于10的进制用字母表示
-   负数一般题目不涉及，或单独处理符号

### 3. 图形输出

**常见图形：**
-   **三角形**（正三角、倒三角、等腰）
-   **菱形**（上下两个三角拼接）
-   **方阵 / 矩阵**（螺旋矩阵、蛇形矩阵）
-   **空心图形**（空心菱形、空心正方形）

**等腰三角形模板（n 行）：**

```cpp
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n - i; j++) cout << ' ';   // 前导空格
    for (int j = 1; j <= 2*i - 1; j++) cout << '*'; // 星号
    cout << '\n';
}
```

**菱形模板（n 为奇数，上半含中间行）：**

```cpp
int mid = (n + 1) / 2;
for (int i = 1; i <= mid; i++) {          // 上半 + 中间
    for (int j = 1; j <= mid - i; j++) cout << ' ';
    for (int j = 1; j <= 2*i - 1; j++) cout << '*';
    cout << '\n';
}
for (int i = mid - 1; i >= 1; i--) {      // 下半
    for (int j = 1; j <= mid - i; j++) cout << ' ';
    for (int j = 1; j <= 2*i - 1; j++) cout << '*';
    cout << '\n';
}
```

**螺旋矩阵思路：**

-   方向数组 + 边界判断，走到边界或已填位置就转向
-   用 `vis` 数组或判断下一个格子是否已填

**易错：**

-   每行末尾**不要多输出空格**（有些题严格比对）
-   行末换行符用 `'\n'`
-   空心图形内部空格数计算
-   对称性：下半部分用 `i--` 循环

### 4. 方向移动

**方向数组（四方向）：**

```cpp
int dx[4] = {0, 0, 1, -1};
int dy[4] = {1, -1, 0, 0};
// 对应：右、左、下、上
```

**八方向（含斜向）：**

```cpp
int dx[8] = {-1,-1,-1, 0, 0, 1, 1, 1};
int dy[8] = {-1, 0, 1,-1, 1,-1, 0, 1};
```

**标准移动框架：**

```cpp
int x = 0, y = 0;              // 当前位置
for (int i = 0; i < k; i++) {  // k 步或指令
    int nx = x + dx[dir];
    int ny = y + dy[dir];
    if (nx >= 0 && nx < n && ny >= 0 && ny < m && !vis[nx][ny]) {
        x = nx; y = ny;
        vis[x][y] = 1;
    }
    // 否则：不移动 / 转向 / 按题目要求处理
}
```

**常见考法：**

-   机器人按指令走（U/D/L/R 或数字方向）
    
-   走格子统计经过的格子数
    
-   碰壁后转向（如螺旋）
    
-   走迷宫（BFS 基础，但 J 组多为模拟直线走）
    

**易错：**

-   **行列顺序**：`x` 是行还是列？`dx` 对应行变化还是列变化？务必统一
    
-   边界是 `0 ~ n-1` 还是 `1 ~ n`
    
-   起点是否标记已访问
    
-   转向时方向编号的循环（`dir = (dir + 1) % 4`）
    
-   指令字符映射到方向数组下标

### 5. 简单游戏规则

**报数问题（逢7过 / 逢某数跳过）：**

```cpp
for (int i = 1; i <= n; i++) {
    if (i % 7 == 0 || 含7(i)) continue;  // 跳过
    // 处理 i
}
```

**约瑟夫环（模拟版，n 较小）：**

```cpp
// n 个人围圈，数到 m 出圈
int cnt = 0, out = 0, i = 0;
while (out < n - 1) {
    if (!vis[i]) {
        cnt++;
        if (cnt == m) {
            vis[i] = 1; out++; cnt = 0;
        }
    }
    i = (i + 1) % n;
}
// 剩下的那个 vis == 0 的就是答案
```

### 易错点

-   数组下标从0还是1开始
-   读入格式（有没有空格/回车）
-   循环范围是`<=`还是`<`
