## J1 模拟

### 常考类型

1.  **日期计算**：闰年判断、某年某月某日是星期几
2.  **进制转换**：十进制转二进制/十六进制，或反向
3.  **图形输出**：打印三角形、菱形、方阵
4.  **方向移动**：机器人走格子，上下左右
5.  **简单游戏规则**：报数、约瑟夫环（模拟版）

### 核心技能

-   **方向数组**：
```cpp
int dx[4] = {0, 0, 1, -1};
int dy[4] = {1, -1, 0, 0};
```
-   **边界判断**：`if (x>=0 && x<n && y>=0 && y<m)`
-   **循环终止条件**：仔细看题目，避免死循环

### 易错点

-   数组下标从0还是1开始
-   读入格式（有没有空格/回车）
-   循环范围是`<=`还是`<`
